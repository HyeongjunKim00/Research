# Folder Structure

- `00_Rules`: 공통 AI 규칙, 연구자 맥락, 우선순위, 핸드오프
- `01_Knowledge`: 분야별 참고 지식과 문헌 색인
- `02_Projects`: 연구 단위의 설계, 시뮬레이션, 실험, 분석, 산출물
- `03_AI_Workspace`: 임시·생성 파일. 검토 후 관련 프로젝트로 이동
- `04_Templates`: 프로젝트와 반복 기록 템플릿
- `99_Archive`: 종료 프로젝트와 대체된 문서

원본 데이터는 그 출처와 프로젝트 맥락을 유지한다. AI 임시 결과는 검토 후에만 정식 기록으로 승격한다.
