# V-Die Cu-Pillar Inter-Die Liquid Cooling

## 연구 맥락
현재 저장소 맥락에 따르면 해석과 thermal test vehicle 실험 검증을 계획 중이다. 결과는 검증 전까지 확정된 것으로 기술하지 않는다. V-Die 구조, direct-to-silicon, conventional cold plate/heat sink의 구조와 선행기술 범위를 구분한다.

## 기록 원칙
구체적 설계 결정, 근거, 미결정 사항은 `Research_Log.md`에 출처와 함께 기록한다. 열저항·온도 기준·유량·열부하 정의가 다른 결과는 직접 비교하지 않는다.
