## 2. 냉각 한계 ladder (§3.2, §3.3, p.33–43)
| 냉각 방식 | 한계 heat flux [B] | 비고 |
|---|---|---|
| 공랭 히트싱크 | ~40–84 W/cm² | 45–50°C 예산 시 40–53 W/cm² |
| 칩스케일 콜드플레이트(불화탄소) | 100–300 W/cm² | [41-44] |
| 워터 제트 임핀지먼트 | 300–450 W/cm² | 칩스케일 |
| 에칭 Si 마이크로채널 | 790 W/cm² @ΔT71°C (Tuckerman-Pease); 매니폴드 1020 W/cm² (5×5mm), 핫스팟 2700 W/cm² | p.35, 37–38 |
| 2상(2-phase) DTC | >1000 W/cm² | ICECool 등 |

**P10 경계조건 검증:** 콜드플레이트 h=30,000 W/m²K = 3 W/cm²K. ΔT~50°C 가정 시 유효 flux ≈ **150 W/cm²** → "직접 액냉 / 제트 임핀지먼트 / 마이크로채널" 구간에 안착. 논문이 *"representative of microchannel or jet impingement cooling"* 라 한 것과 **[B] 정합**. 즉 우리 상단 경계는 실존 고성능 액냉 수준으로 과하지 않음.
(단위면적 열저항 참고: 공랭 0.8, 액냉 병렬채널 0.35 @170 W/cm², 분리형 원격액냉 0.1 °C·cm²/W.)

## 3. 핫스팟 온도 한계 기준 (§2.9, HotGauge Fig.24, p.17–19)
- 칩 핫스팟 **>100°C** 는 신뢰성 우려. **80°C** 라도 공간기울기(MLTD)>25°C 면 타이밍 실패 우려.
- HBM(메모리)은 로직보다 **Tjmax 가 더 빡빡**(일반적으로 ~95–105°C급) — "cold plate 는 보통 로직 die 에 최적화돼 HBM 의 열요구를 충분히 못 맞춘다" 명시(§3, p.3).
- **Phase 4 용도:** 플롯에 GPU/HBM 각 Tjmax 한계선을 그릴 때 이 기준을 근거로 쓸 수 있음 (단, 구체 Tjmax 는 소자 datasheet [A] 로 별도 확정 필요).

## 4. TIM / 재료 (§3.4, §3.5, p.28–35)
- TIM 후보 k: 인듐계 LMP 솔더 ~70 W/mK, PCM-TIM 5.4 W/mK, 나노스프링 insulance <0.5 mm²K/W.
- 2D HI 과제로 "TIM1 insulance(K·mm²/W) 불확실성 — form factor·warpage 증가로" 명시(§2.1).
- **P10 용도:** TIM k·두께 가정의 범위 근거. (현재 모델 TIM 두께 0.2 mm; k 는 `hbm_gpu_2p5d.py` K dict 참조.)

## 5. P10 에 당장 반영할 점
1. **경계조건(h=30000) 타당성 확인됨** → Research_Log 검증 항목에 [B] 근거 보강 가능.
2. **HBM 40 W 는 보수적** — Phase 3/5 에서 60 W/스택을 상한 시나리오로 추가 고려.
3. **우리 GPU 핫스팟 맵은 HIR 추세(>4 W/mm²)보다 완만** — 69.1°C 앵커는 유지되나, "핫스팟 첨예도"를 논문/실제와 비교할 땐 이 보수성을 명시.
4. **Phase 4 한계선**: 핫스팟 >100°C, HBM Tjmax ~95–105°C 를 플롯 기준선 후보로.
